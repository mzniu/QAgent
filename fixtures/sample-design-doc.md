# 在线图书借阅系统设计说明（示例）

本文档为 QAgent v0.1 冒烟测试用样例，不代表真实产品。

## 1. 背景

图书馆需要一套 Web 借阅系统，支持读者检索、预约、借阅与归还。

## 2. 功能需求

### 2.1 用户注册与登录

读者可使用邮箱注册账号，登录后维持会话 24 小时。密码强度至少 8 位。

### 2.2 图书目录检索

支持按书名、作者、ISBN 关键字检索；结果分页，每页 20 条。

### 2.3 借阅与归还

已登录读者可借阅在架图书，每人最多同时借阅 5 册，借期 30 天。
归还后库存实时更新。

### 2.4 预约队列

当图书全部借出时，读者可加入预约队列；到货后邮件通知（24 小时内有效）。

## 3. 非功能需求

- API 响应时间 P95 < 500ms（检索接口）
- 审计日志保留 90 天

## 4. REST API（概要）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/auth/register | 注册 |
| POST | /api/v1/auth/login | 登录 |
| GET | /api/v1/books | 检索 |
| POST | /api/v1/loans | 借书 |
| POST | /api/v1/loans/{id}/return | 还书 |

## 5. 验收标准

- 管理员可导入 MARC 书目 batch
- 读者端支持 Chrome / Edge 最新两个大版本
